# Layouts

Manera de organizar los componentes gráficos de una interfaz.

* Vertical -> QVBoxLayout
* Horizontal -> QHBoxLayout
* Rejas o celdas -> QGridLayout

# Ejercicio para casa

* Interfaz con un contador.
* Quiero que tenga un input el usuario para que pueda introducir un numero.
* Dos botones, uno para sumar y otra restar.
* Controle el error de lo que el usuario esta introduciendo por teclado sea un número.
* Dependiendo del valor del contador:
1) Si es 0 -> Quiero que aparezca amarillo.
2) Si es menor de 0 -> Quiero que aparezca siendo rojo.
3) Si es mayor de 0 -> Quiero que aparezca verde.
